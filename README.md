# Тренажёр 7 (Flutter)

Мобильная игра на запоминание и распознавание лиц с фотореалистичными
лицами из StyleGAN. Три режима, три уровня сложности, комбо-очки.

## Режимы
| Режим | Суть |
|---|---|
| Запомни лицо | Лицо показывают несколько секунд, затем нужно выбрать его среди вариантов |
| Запомни несколько лиц | Запоминаете 2–4 лица и отмечаете каждое в сетке |
| Найди в толпе | Поиск заданного лица в толпе на время |

## Запуск
```bash
flutter pub get
flutter run
```

## Работа без интернета

Игра использует 60 портретов, которые загружаются во время сборки и
встраиваются в APK как локальные assets. После установки интернет не нужен.
При сборке через GitHub Actions шаг `Bundle offline portraits into the app`
подготавливает изображения автоматически.

Для локальной сборки с интернетом выполните:
```bash
bash tools/download_faces.sh 60
flutter pub get
flutter build apk --release
```

## Архитектура
- `lib/models.dart` — режимы и параметры сложности (вся балансировка здесь)
- `lib/face_provider.dart` — источник лиц (интерфейс + 2 реализации)
- `lib/game_screen.dart` — игровой цикл: показ → выбор → очки/жизни
- `lib/main.dart` — меню

Чтобы добавить свой источник лиц, унаследуйтесь от `FaceProvider`.

## Примечание про «похожих» персонажей
GAN выдаёт случайные лица, поэтому точно контролировать «похожесть»
отвлекающих вариантов нельзя — сложность нарастает за счёт количества
и времени. Если понадобится режим с гарантированно похожими лицами,
генерируйте пул лиц с атрибутами и отбирайте дистракторы по близости
в пространстве признаков (например, эмбеддинги InsightFace).

## Сборка APK без установки Flutter (GitHub Actions)

1. Создайте аккаунт на github.com и репозиторий (например, `face-hunt`).
2. Загрузите файлы проекта в репозиторий (можно перетащить папку
   прямо в браузере на странице «uploading an existing file» —
   файл `.github/workflows/build-apk.yml` обязан попасть туда же).
3. Откройте вкладку **Actions** в репозитории — сборка запустится
   автоматически (займёт 5–10 минут, в первый раз дольше).
4. Откройте завершённый запуск → раздел **Artifacts** → скачайте
   `face-hunt-apk.zip`.
5. Перекиньте zip на телефон, распакуйте и установите `app-release.apk`
   (Android попросит разрешить установку из неизвестных источников).
